# Mater Dei — site

Projeto estático para GitHub Pages.

## Publicação
1. Extraia este ZIP.
2. Entre no repositório da Mater Dei no GitHub.
3. Envie `index.html` e a pasta `imagens` para a raiz do repositório.
4. O GitHub Pages usará o `index.html` como página inicial.

## Observação
Os produtos, preços e nomes de peças marcados como provisórios devem ser ajustados quando o catálogo definitivo estiver fechado.

A área de login não armazena senhas no HTML. Para autenticação real e segura será necessário backend/serviço de autenticação.
